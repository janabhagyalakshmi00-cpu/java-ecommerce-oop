# Java E-Commerce OOP

A console-based e-commerce application developed in Java to practice and demonstrate Object-Oriented Programming concepts through a simple e-commerce system.

## About the Project

This project simulates basic e-commerce operations using Java and OOP concepts.

The application includes products, customers, administrators, a shopping cart, and orders.

## Features

- Product management
- Customer information management
- Admin functionality
- Add products to cart
- Remove products from cart
- View cart
- Calculate total cart price
- Create and manage orders
- Update order status

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Java Collections

## OOP Concepts Used

- Classes and Objects
- Constructors
- Parameterized Constructors
- `this` keyword
- Inheritance
- Method Overriding
- Encapsulation
- Polymorphism
- `super` keyword
